# Portfolio Website (2026)

A modern, responsive personal portfolio built with React to showcase my web development projects, technical skills, and contact details.

## Live Demo

https://react-portfolio-2026-q1dv6t7tj-tonyystaaarks-projects.vercel.app/

## Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
- **Project Showcase:** Highlights key web development projects with live demos and repository links.
- **Interactive UI:** Smooth navigation, clean layout, and modern UI components.
- **Contact Section:** Direct channels for potential clients, collaborators, or employers to reach out.

## Tech Stack

- **Frontend:** React, HTML5, CSS3 / Tailwind CSS
- **Deployment:** cPanel / z.com / GitHub Pages
